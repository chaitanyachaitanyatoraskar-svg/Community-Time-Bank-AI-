MatchScore = S_skill (40%) + S_avail (25%) + S_location (15%) + S_rating (10%) + S_reliability (10%)
Factor & Weight Code Reference Algorithmic Evaluation Logic
Skill Relevance (40%) lines 95–119 Evaluates proficiency tier: Expert = 40 pts, Intermediate = 32 pts, Beginner = 24 pts. Each additional relevant skill adds +4 pts. Partial category matches yield a 20 pt baseline.
Availability (25%) lines 121–141 Awards 25 pts for exact weekday overlap with preferred dates. General active schedule slots award 15 pts.

3.2 Bilateral Double-Confirmation Settlement — server/src/services/ledgerService.ts

Core Question: “How do you prevent fraud or one person falsely claiming they completed a session?”
What to say: “Ma’am, credits never transfer automatically. We enforce a two-party confirmation gate. Only when both parties independently submit their completion confirmation does the atomic transaction execute.”

Code Logic (lines 66–148): 
const requesterConfirmed = allConfirmations.some(c => c.userId === booking.requesterId);
const helperConfirmed = allConfirmations.some(c => c.userId === booking.helperId);

if (requesterConfirmed && helperConfirmed) {
  await prisma.$transaction(async (tx) => {
    await tx.booking.update({ where: { id: bookingId }, data: { status: 'COMPLETED' } });
    await tx.user.update({ where: { id: booking.requesterId }, data: { creditBalance: { decrement: transferAmount } } });
    await tx.user.update({ where: { id: booking.helperId }, data: { creditBalance: { increment: transferAmount } } });
    await tx.creditTransaction.create({ data: { bookingId, fromUserId: booking.requesterId, toUserId: booking.helperId, amount: transferAmount, ... } });
  });
}

Why this matters to examiners: prisma.$transaction guarantees atomicity. If the server loses connection mid-transfer, all operations roll back completely, ensuring zero credit corruption and double-spending protection.

3.3 The Fair Credit Multiplier System — listings.ts & bookings.ts

Core Question: “Why should all hours be equal if some tasks require expensive equipment or high physical risk?”
What to say: “Ma’am, to accommodate specialized tasks without introducing monetary inflation, we created a governed Fair Credit Multiplier System capped strictly at three tiers:”

TransferAmount = ServiceDurationInHours × AgreedMultiplier
  • 1.0× STANDARD Peer tutoring, language conversation, general neighborhood gardening.
  • 1.25× INTERMEDIATE Certified instruction, complex software debugging, specialized tools.
  • 1.5× ADVANCED CAP Component-level hardware repair, hazardous equipment, emergency support. Strictly capped at 1.5×.

Anti-Gouging Enforcement: The client cannot pass arbitrary rates (e.g. 4.0×). The backend strictly validates ALLOWED_MULTIPLIERS = [1.0, 1.25, 1.5] and rejects unapproved values with HTTP 400. Once accepted, agreedMultiplier is permanently immutable.

4. Top 5 Viva Questions & Bulletproof Answers

Q1: “Why Time Credits instead of integrating a normal payment gateway like Stripe?”
“Ma’am, commercial gig platforms prioritize those with surplus money. In a college campus, many students have valuable skills (like coding or design) but lack disposable cash. Time Banking creates an egalitarian social safety net: one hour of service rendered equals one hour of service received, fostering community solidarity and mutual aid without monetary barriers.”
Q2: “How do you prevent two friends from creating fake bookings to inflate their credits?”
“First, our credit economy is closed-loop: to give 2 credits to a helper, the requester must already hold those 2 credits in their wallet balance, which are immediately deducted. Second, every new account starts with only 3 welcome credits, so balance generation is strictly bounded. Third, our Admin Moderation Panel tracks transaction velocity and can freeze suspicious accounts.”
Q3: “Why did you choose Prisma ORM over raw SQL or Mongoose?”
“Prisma delivers end-to-end compile-time type safety: schema definitions automatically generate TypeScript types, meaning typos in column names are caught during compilation rather than in production. Furthermore, Prisma interactive transactions (prisma.$transaction) simplify complex multi-table ACID operations, guaranteeing financial consistency.”
Q4: “What happens if there is a dispute or a helper does not show up?”
“In our Booking state machine, bookings can transition to DISPUTED. Clicking ‘Report Issue / Dispute’ automatically halts the credit transfer, alerts the Campus Administrator at /admin, and enables the administrator to inspect communication records and issue a binding credit refund or adjustment with mandatory audit reasons.”
Q5: “Can users cash out their time credits for real fiat currency?”
“No Ma’am, direct cash conversions are strictly prohibited to preserve the non-commercial spirit of community service. Instead, surplus credits can be donated to the Community Credit Pool to fund hardship grants for peers, or redeemed in the Perks Catalog for sponsor-donated cafe coupons or campus event passes.”
